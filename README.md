# Los Gatos Mágicos: Aventura de Fuego y Agua

Proyecto integrador de primer nivel · Lógica de Programación · UIDE · Paralelo C

Juego cooperativo por turnos para dos jugadores sobre un tablero de 5 × 5 con modo local y, más adelante, modo multijugador cliente-servidor en red LAN.
